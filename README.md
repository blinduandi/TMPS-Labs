## Labs

### Lab 1 - SOLID Principles Coffee Shop
A comprehensive demonstration of all five SOLID principles using a real-world coffee shop example.

- **Location:** `lab1/`
- **Language:** Java
- **Files:** 11 Java classes demonstrating enterprise-level design
- **Principles:** S, O, L, I, D (all SOLID principles)

**Features:**
- ☕ Coffee shop ordering system
- 💳 Multiple discount types (Student, VIP, Percentage)
- 🔧 Service-oriented architecture
- 📱 Notification system
- 🧪 Easy to test and extend

**Quick Start:**
```bash
cd lab1/src
javac --release 17 coffeeshop\*.java coffeeshop\domain\*.java coffeeshop\service\*.java coffeeshop\discount\*.java
java coffeeshop.CoffeeShopDemo
```

For detailed explanation, see: [Lab 1 Report](lab1/REPORT.md)
